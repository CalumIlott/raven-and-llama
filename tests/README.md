# Test Suite

Run all checks with `npm test` (Node.js 22.5 or newer). After `npm ci`, install Chromium once with `npx playwright install chromium`. Run `npm run test:css` to verify committed generated assets; unit and integration suites use Node's built-in test runner, Wrangler dry-runs the Worker bundle, Playwright covers desktop and mobile Chromium, and `npm run audit` checks dependencies.

## Coverage

- `unit/curriculum.test.js` checks belt ordering, unique identifiers, skill metadata, and arcade definitions.
- `unit/generators.test.js` exercises standard and hard question generation for every curriculum skill, answer options, choice generation, shuffling, and belt exams; it requires 100 distinct standard questions per skill where the taught number range allows it and asserts the exact size of finite fact sets.
- `unit/number-builder.test.js` checks ascending and descending integer sequences, difficulty bounds, question IDs, and input limits.
- `unit/missing-number.test.js` checks explicit sequence rules, answer uniqueness, difficulty bounds, replay variation, and invalid input handling.
- `unit/money.test.js` checks Australian denominations, integer-cent totals, exact Shopkeeper change, tender validation, and Money Masters scoring.
- `unit/fraction-pizza.test.js` checks proper, equivalent, and mixed-number fraction models, quiz validation, stable IDs, and invalid input handling.
- `unit/activity-engine.test.js` checks activity definition validation, quiz and game lifecycle tracking, finalized question accuracy, incomplete-run cancellation, and one-time completion.
- `unit/spelling-safari.test.js` checks activity definitions, unique answerable rounds, scramble character preservation, repeated and punctuated letters, answer normalization, empty pools, and invalid activity handling.
- `unit/solar-system.test.js` checks the canonical answer order, randomized tray contents, stable skill mapping, unique placement rules, corrective feedback, and shared activity scoring.
- `unit/geography-world.test.js` validates the sourced country dataset, unique country identifiers, simplified map geometry, and coverage across inhabited continents. `e2e/geography-world.spec.js` checks mobile map-marker alignment, keyboard/list/country-picker selection, zoom controls, and route behavior.
- `unit/geography-country-activities.test.js` checks flag and capital question uniqueness, complete answer choices, incomplete/ambiguous record exclusion, retries, and one-time ActivityEngine progress. `e2e/geography-country-activities.spec.js` checks both modes, keyboard and touch answers, retry, completion, direct routes, and return navigation on desktop and mobile Chromium.
- `unit/accounts.test.js` checks temporary guest state, session restoration, account-scoped skill and activity progress sync, accumulated quiz accuracy, configured star awards, memory-only guest spelling lists, profile list validation, training aggregation, final-exam prerequisites, and graduation/certificate recording.
- `unit/account-api.test.mjs` checks input validation, password hashing, secure sessions, owner-scoped progress and spelling lists, bounded list validation, password changes, account deletion, same-origin protections, and auth throttling behavior.
- `unit/plant-life-cycle.test.js` checks the canonical stage sequence, stage metadata, unique placement rules, relationship-based feedback, and shared activity scoring.
- `unit/food-chains.test.js` validates sourced ecosystem records and producer-consumer links, unique organism placement, relationship feedback, and one-time ActivityEngine progress.
- `unit/history-timeline.test.js` validates sourced event records and approximate chronology, event placement/reordering, corrective feedback data, and one-time ActivityEngine progress recording.
- `unit/brain-power.test.js` checks unique number-pattern solutions, deterministic Memory Match shuffles and matched-card transitions, unique Code Breaker clues, and one-time ActivityEngine completion for all three games.
- `unit/party-planner.test.js` checks item validation, bounded quantities, integer-cent totals, required items, under/exact/over-budget evaluation, and one-time ActivityEngine completion.
- `unit/virtual-lab.test.js` checks curated simulation rules, safe unsupported combinations, workspace placement, reset behavior, and shared activity scoring.
- `unit/worker-auth-rate-limit.test.mjs` checks Worker rate-limit keys and denied decisions without remote bindings.
- `unit/local-account-store.test.js` checks SQLite persistence, legacy JSON import, session expiry, account deletion, and concurrent writes from separate Node processes.
- `integration/server.test.js` starts the HTTP server with a temporary data directory and verifies registration, login, owner-only skill/activity progress and spelling-list persistence, logout, malformed input, legacy endpoint rejection, and private-file protection.
- `integration/worker.test.js` runs the Worker locally with Wrangler and temporary D1 persistence, then checks headers, registration, session restore, skill/activity progress and spelling-list persistence, origin protection, and rate limiting without remote resources.
- `e2e/navigation.spec.js` checks home/module navigation and scroll-to-top behavior, Maths World topic filters, Number Builder keyboard/retry/progress flows, separate curriculum and Learning Centre report sections, curriculum counts, locked exam prerequisites, a failed exam, retry, the 80% pass threshold, and the Stage 2 unlock.
- `e2e/missing-number.spec.js` checks generated answer selection, retry feedback, one-time progress recording, replay variation, and Maths World return navigation on desktop and mobile Chromium.
- `e2e/fraction-pizza.spec.js` checks slice placement by touch/click, keyboard and drag-and-drop input with shared drag feedback, retry, quiz completion, and activity score and accuracy reporting on desktop and mobile Chromium.
- `e2e/spelling-safari.spec.js` completes all four spelling adventures, checks Jungle Jumble retry, empty-pool and speech fallback behavior, verifies pronunciation without answer disclosure, and tests parent list CRUD flowing into typed-answer Spell It and its activity report row on desktop and mobile.
- `e2e/solar-system.spec.js` checks the refresh-safe Science Lab route, shuffled planet tray, shared drag cursor/preview/drop feedback, existing Science Explorers navigation, accessible planet facts, keyboard/touch placement, retry feedback, completion, and return navigation on desktop and mobile Chromium.
- `e2e/history-timeline.spec.js` checks the refresh-safe History hub route, browser navigation, keyboard placement, drag-and-drop from the card tray, drag reordering, sourced event details, corrective retry, chronological completion, and one-time progress/stars on desktop and mobile Chromium.
- `e2e/brain-power.spec.js` checks direct hub navigation, keyboard pattern retries, Memory Match pair state, clue-based Code Breaker feedback and completion, and return navigation on desktop and mobile Chromium.
- `e2e/plan-party.spec.js` checks the refresh-safe activity route, keyboard and touch quantity controls, live budget totals, over-budget retry, exact-budget completion, shared progress, and return to existing Life Skills programs on desktop and mobile Chromium.
- `e2e/geography-world.spec.js` checks the refresh-safe Geography hub route, map and list selection, shared country facts, keyboard activation, speech fallback, and return navigation on desktop and mobile Chromium.
- `unit/spelling-pronunciation.test.js` checks local voice selection/loading, playback cancellation, muted and unsupported-browser feedback, and default-voice fallback.
- `e2e/plant-life-cycle.spec.js` checks stage labels and explanations, keyboard/touch/drag ordering with the shared drag cursor, next/previous-stage feedback, retry, completion, and return navigation on desktop and mobile Chromium.
- `e2e/food-chains.spec.js` checks the Science Lab entry point, sourced chain facts, keyboard/touch/drag placement, relationship feedback and retry, three-chain completion, one-time progress recording, and return navigation on desktop and mobile Chromium.
- `e2e/virtual-lab.spec.js` checks safe simulation notices, supported and unsupported combinations, reset behavior, keyboard/touch/drag input with shared drag feedback, deterministic explanations, and one-time activity and star recording on desktop and mobile Chromium.
- `e2e/shopkeeper.spec.js` completes Shopkeeper transactions using desktop drag-and-drop with the shared copy cursor and drop target feedback, keyboard controls, and mobile touch selection.
- `e2e/accounts.spec.js` checks guest notice, registration, session restore, password change, login, logout, account deletion, and progress sync across separate browser contexts with account isolation.
- `e2e/workflows.spec.js` checks full skill training and progress, all three Times Tables quiz modes, Product Pair Match scoring, all seven belt arcade launch/exit paths, progress reporting, and the trophy room.
- `e2e/accessibility.spec.js` checks semantic keyboard navigation, dialog focus trapping/restoration, Escape-to-close, narrow-screen overflow, and WCAG AA text contrast across Maths World, Number Builder, and Shopkeeper in both themes, including feedback and results. The same tests run in desktop Chromium and Pixel 7 emulation.

E2E tests use temporary account data and Playwright output directories, so they never modify local learner data or place Windows trace files under a synced workspace. GitHub Actions verifies generated assets are committed, runs unit/integration tests on Node.js 22, 24, and 26, validates the Worker bundle with Wrangler, runs desktop/mobile browser tests, and audits dependencies for pull requests targeting `main`. `npm test` runs the four test suites; `npm run test:css` and `npm run audit` are separate gates.
